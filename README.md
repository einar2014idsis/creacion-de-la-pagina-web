# Página web basada en eBusiness

Archivo HTML de una página corporativa basada en la plantilla **eBusiness** de BootstrapMade. Es un ejemplo de estructura de una página web con secciones y referencias a estilos y bibliotecas externas.

## Contenido y tecnologías

- `index.html`: marcado de la página, metadatos y referencias a recursos.
- HTML, Bootstrap y referencias a bibliotecas de presentación como Nivo Slider, Owl Carousel, Font Awesome y VenoBox.
- El propio HTML conserva la atribución de la plantilla a BootstrapMade; revisa sus condiciones de uso antes de redistribuirla.

## Ejecución y limitaciones

Abre `index.html` en un navegador para inspeccionar el marcado. El repositorio solo contiene ese archivo: las carpetas locales `css/`, `lib/`, `img/` y otros recursos referenciados no están incluidas, por lo que la presentación y las funciones dependientes de esos archivos pueden no funcionar. Para reproducir la plantilla completa se necesitan los recursos correspondientes y sus licencias.
